## The Core Concept

> AI has no memory. Every time you start a new chat, you're talking to someone who has never met you.

The workshop teaches Protocol — habits that give AI persistent memory. The core idea is a trade: you invest a small percentage of your context window in structured markdown files, and in return your AI never forgets your decisions, patterns, or constraints. Without that trade, you spend 30% of every session re-explaining. With it, each session builds on the last. Files in Git that compound over time.
