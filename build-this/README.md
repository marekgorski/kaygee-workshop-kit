# Build This

**Generator files for the KayGee Workshop Kit.**

Each file in this folder is a self-contained generator. Copy it to an empty folder, open Claude Code, and run it.

---

## How to Use

1. **Copy a BUILD file** to an empty folder on your machine
2. **Open a terminal** and `cd` into that folder
3. **Run `claude`** to start Claude Code
4. **Allow folder access** — Claude will ask permission to work in this folder. Allow it.
5. **Prompt:** `read and follow BUILD_GYM.md` (or whichever file)
6. **Follow along** — Claude will guide you through building the project

## Key Properties

- **Self-contained:** Each file works in isolation (no dependencies on this repo)
- **Generative:** Creates app code + protocol files at runtime
- **Educational:** Teaches Claude workflow as you build (permission prompts, etc.)
- **Single + Multiplayer:** Works for solo learners AND workshop groups

## Contributing

Have an idea for a new build file? PRs welcome.

A good build file:
- Works when copied to an empty folder
- Checks prerequisites and guides if missing
- Explains the permission model to the user
- Generates a complete, working project
- Creates appropriate protocol files
