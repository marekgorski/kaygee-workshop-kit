## Morning Block (9:00 AM – 12:20 PM)

**Goal:** Build the full stack on rails (everyone on gym app)

### 9:00 – 9:45 | Session 1: Protocol
- Clone workshop repo
- Demo problem (without protocol) vs solution (with protocol)
- Everyone adds rest timer feature
- **Key moment:** Non-determinism demo
- **Energy:** "That was fast. And it worked."

### 9:45 – 9:50 | BIO BREAK
- Quick 5-minute stretch
- Helpers: Check anyone having issues

### 9:50 – 10:35 | Session 2: Git
- Demo the "can't undo" problem
- Git basics: Work → Stage → Commit → Push
- Everyone pushes to their own GitHub
- Update PROGRESS.md
- **Energy:** "My code is safe now."

### 10:35 – 10:50 | BREAK
- Bathroom, coffee, snacks
- Helpers: Catch up anyone behind

### 10:50 – 11:35 | Session 3: Deploy
- Demo the "can't share localhost" problem
- Connect GitHub to Vercel
- Everyone gets a live URL
- Test auto-deploy on push
- **Energy:** "I shipped to the internet."

### 11:35 – 12:20 | Session 4: Data
- Demo the "data disappears on refresh" problem
- Set up Supabase
- Create workouts table
- Connect app to Supabase
- Data persists
- **Energy:** "My app is real now."

**60 minutes**

- **Helpers:** Catch up anyone whose Supabase isn't working

## Afternoon Block (1:20 – 3:15 PM)

**Goal:** Design alignment + team cooperation

### 1:20 – 2:05 | Session 5: Recovering from Failures
- Demo design drift problem
- Show Figma Make
- Explain the handoff point
- **Pivot to own idea:** Everyone starts their hackathon project
- **Energy:** "I have my own thing now."

### 2:05 – 2:15 | BREAK
- Quick 10-minute stretch

### 2:15 – 3:00 | Session 6: Building Shared Context
- Form hackathon teams
- Collaboration exercise: read someone else's Protocol files
- Teams set up hackathon project with CLAUDE.md and TODO.md
- Closing recap
- **Energy:** "We're ready to build — and every session will compound."

### 3:00 – 3:15 | BUFFER / Q&A
- Overflow time if running behind
- Q&A if on schedule
- Final goodbyes

## Notes for Facilitators

**Morning vs Afternoon:**
- Morning: Tight rails, everyone together, heavy narration
- Afternoon: Looser, freedom to explore, more individual support

**Energy management:**
- Session 3 (Deploy) is the morning peak — celebrate it
- Post-lunch energy dip is real — Session 5 pivot helps (new energy from own idea)
- Session 6 should feel exciting, not exhausting

**Helpers:**
- Morning: Watch for setup issues, npm problems, Git authentication
- Afternoon: Help with Supabase debugging, idea scoping, Protocol file writing
